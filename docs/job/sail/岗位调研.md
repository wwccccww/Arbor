## 核心能力关键词（简历靶心，3–5 个）

从 JD1 + JD3 收敛，不堆词：

1. **记忆管理**：短期会话 vs 长期知识；谁能读、谁能写；冲突怎么进人工确认
2. **上下文工程**：什么进模型、按什么顺序、窗口不够怎么裁、引用能不能追
3. **工具调用**：白名单、接到日历/工单等业务系统，而不是模型随便调
4. **RAG 与评测**：召回对比、泄漏为零的硬门槛、生成胡编与隔离分家
5. **工程落地**：异步导入、流式对话、接口与工作流接入（实习锚点）

## 隐性门槛（面试一定会碰）

- 项目是不是 Demo：美团一面凉经指向「工具失败怎么办、召回怎么排查」。Arbor 有评测和隔离测试，但没有生产线指标——要主动说清边界。
- 「为什么不用 LangChain」：JD 常写了解框架。诚实答：领域规则要单测，所以自研编排；了解框架分层，没有把它当领域模型。
- 实习深度：任务是接口级实现，不要讲成「负责数据中台」。
- 数字口径：0.92 / 0.70 来自自建金标 + 夹具嵌入，不是线上 bge、不是生产流量。
- 代码归属：Arbor 是可演示开源项目，用了大模型辅助开发；面试讲清自己做的决策（分层、隔离、评测），不要装成带团队的 owner。
