## 核心项目

**Arbor｜数字员工工作台**　　独立项目 · 可演示开源  
Python · PostgreSQL（含向量检索）· Redis · 大模型对话 / 抽取

- **记忆管理：** 多人共用时纯向量会串知识。档案、摘要、经历目录和细节检索分层处理；回复只引用本轮注入的材料。一线可对话、主管才能改知识；没读权限的内容不进入模型上下文。
- **上下文与 RAG 评测：** 身份走结构化档案，不靠向量碰运气；因果类问题先定位经历再取细节，并与关键词融合，窗口按相关度裁剪。冻结题集回测：分层相对纯向量，身份约 0.63→1.0，Top5 召回约 0.70→0.92，跨工作空间泄漏为 0。数字来自自建金标与夹具嵌入，不是生产流量；生成是否胡编只检查是否超出本轮已提供文本。
- **工具调用与工程落地：** 文档和语音异步解析后进入待确认，人确认才落成知识，冲突不静默覆盖。日历查询、工单登记按数字员工白名单做函数调用。对话支持流式输出。AI 编程辅助完成可演示系统，隔离、引用校验和评测口径由自己定。
