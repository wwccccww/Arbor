## 不会就不会

| 被问到 | 安全回答 |
|--------|----------|
| 为什么不用 LangChain？ | 我了解它适合快速拼链路。Arbor 要把隔离和记忆规则做成可单测的领域逻辑，所以编排写在应用层。没有把框架当业务模型，也没有生产级 LangGraph 经验。 |
| MCP / A2A / 多智能体怎么做？ | 没做过落地。工具目前是人设白名单加日历、工单适配。协议层我可以学，但不能说已经实现。 |
| 工具调用失败怎么做生产级重试？ | 演示里失败会返回错误、不在白名单不执行。指数退避、幂等键、补偿事务我没有在该项目里做成完整方案，这是我知道的缺口。 |
| 线上召回怎么监控？ | 我有离线冻结题集和检索元数据，没有线上 A/B。排查会先看过滤、再看是否走错层、再看融合。 |
| 实习 SQL 执行安全？ | 我提供的是平台执行入口。如果拦截规则不是我写的，我会说明以平台规范为准，不现场编一套网关。 |
| 代码是不是全自己手写？ | Arbor 有 AI 辅助实现。分层、隔离、评测口径是我定的，我能讲到代码结构和测试。不装带人的 owner。 |
