依据：JD1/JD3 的记忆、上下文、工具、RAG、评测；2026-08 美团 Agent 应用一面从项目开刀，候选人自述失分在工具异常与召回排查（B 级面经，含课程推广，只用来判断题型，不当该公司流程）。

优先 bullet：P1-B1、P1-B2、P1-B3。后端接口问到再落到 E1-B1。

## 开场 30 秒

> 和岗位最相关的是 Arbor：数字员工的记忆和权限，不是聊天套壳。可以按谁来用、记忆怎么分层、工具怎么调、怎么证明没串线来讲。实习是 Java 接调度和采集，用来说明会把内部系统做成可调用接口。

## 高频题（对 Arbor 作答）

1. **架构**：接入鉴权 → 用例（发消息 / 确认知识 / 导入）→ 领域规则 → 库、向量、模型、队列。模型只在已授权、已检索的材料上生成。
2. **为何不是固定流程**：同步一张表用固定流程；找经历并决定是否调日历/工单，路径不固定。不确定的给模型，权限和是否落库由代码决定。
3. **记忆分层**：档案；会话摘要；经历目录；向量细节。长期写入要人确认。
4. **召回变差**：先查工作空间过滤，再查是否错走向量，再查经历命中，再查裁窗。有检索元数据，无线上大盘。
5. **工具失败**：不在白名单不调；失败显式返回。没有完整生产重试，是缺口。
6. **为何不用 LangChain 当底座**：隔离和记忆规则要能单测。了解框架抽象，实现写在应用层。
7. **幻觉**：引用必须属于本轮材料；隔离不靠生成分投票。
