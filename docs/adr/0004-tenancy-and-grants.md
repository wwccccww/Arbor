# ADR 0004：工作空间三角色 + 人设四权

- 状态：已采纳
- 日期：2026-08-19

## 上下文

数字员工需要隔离与授权；陪伴场景只需要「自己的空间」。完整 IAM 中台会压过人设与事件树。

## 决策

- 租户硬隔离。
- 空间角色仅 owner / admin / member。
- 人设能力仅 chat / read_memory / write_memory / admin。
- 无 `read_memory` 的记忆不得进入模型上下文。
- 不做 SSO、字段级权限、跨租户市场。

## 后果

- 授权判定是领域服务，HTTP 层只翻译 403。
- 审计表记录人设变更、导入、确认、导出。
