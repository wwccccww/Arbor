## 项目条目（直接粘这一段）

**Arbor｜数字员工工作台｜独立项目**  
Python · PostgreSQL（含向量检索）· Redis · 大模型对话 / 抽取 · 中文嵌入

团队里要同时跑客服、导师、面试官等数字员工时，最容易出现两件事：知识串到别人身上，以及回答说不清依据。这个项目把「档案、近期摘要、经历目录、细节检索」分开处理，对话只引用本轮真正提供给模型的材料。

在自建评测集上，分层检索相对「只靠向量」：身份类问题从约六成稳定到全部命中，Top5 召回从约 0.70 到约 0.92，跨工作空间泄漏为 0。

- **把隔离做成后端规则，而不是界面隐藏。** 工作空间是硬边界；一线可以对话，主管才能改知识。没有读知识权限时，模型上下文里不会出现知识细节。查询与数据库行级策略双重过滤，隔离用例失败则不允许合并。
- **领域规则与框架、模型供应商脱钩。** 身份、知识、经历、会话分开建模；业务不变式写在领域层。换数据库、换模型、换对象存储只改外围适配。包依赖测试禁止领域层引用 Web 框架——同一套边界可以落在 Spring（Controller 不写业务，领域包不依赖 JPA）。
- **检索按「稳定身份 / 相关经历 / 细节片段」编排，而不是把人设塞进提示词。** 身份走结构化档案，每次必带；「为什么、后来怎样」类问题先定位经历再扩一两跳；细节再走向量与关键词融合排序。窗口不够时按相关度裁剪，模型随口编的依据编号一律丢弃。
- **知识不能模型说了就算。** 手册、工单、文档、语音先异步解析，抽取出的事实进待确认队列，主管确认后才写入档案或经历；与旧设定冲突时标出来，不静默覆盖。数字员工可按白名单查日历、登记工单，工具执行受策略约束。
- **评测是产品能力，用来证明策略而不是刷观感。** 授权和过滤用自动化测试钉死；检索好不好用冻结题集对比多种策略。生成是否胡编，只检查是否超出本轮已经提供的文本，不用生成分代替隔离结论。

投 Java 后端：保留前两条，第三条缩成半句，第五条必留。  
投 Agent / AI 应用：第三、四、五条在前，第一条证明你能把 Agent 接到权限和业务系统里。

## 口述（90 秒，对外词）

**Java 后端**  
这不是聊天框套一层接口。数字员工要进团队，先解决知识和权限。我把身份、知识、经历拆开，能不能读知识、能不能改档案写在领域规则里，不写在 SQL 或提示词里将就。模型、向量库、文件存储都是可替换适配。隔离有查询过滤和数据库行级策略两道，对应测试失败不能合入。如果用 Spring 重做，Web 层和持久化落在外围，领域包保持纯业务。

**AI 应用 / Agent**  
多数做法把人设和资料一起丢进向量，结果是身份不稳、还会串到别人。我把档案做成每次必带的结构化身份，经历目录负责「为什么、后来怎样」，向量只找细节。相对只靠向量，身份题稳定命中，召回大约从 0.70 到 0.92，跨工作空间泄漏是 0。模型引用必须是这轮真正塞进去的材料。知识写入要主管确认。工具按数字员工策略调用，不是全局随便调。

被问「477 道题是不是很大的集」：不是工业语料，是同一批源记忆上的问法扩张，用来对比策略。  
被问「0.92 是线上 embedding 分吗」：合入门禁用夹具嵌入；真实中文嵌入走夜间任务，两套表不混读。  
被问评测夹具里的样本名字：那是隔离测试用的夹具人设，产品是数字员工。

## 面试对照（只给自己看，不要贴简历）

| 对外说法 | 仓库里的名字 | 被追问时怎么接 |
|---|---|---|
| 工作空间 / 数字员工双层隔离 | 租户 ID + 人设 ID；行级安全策略 | 向量检索接口不允许做全局相似度搜索 |
| 一线对话、主管改知识 | 空间三角色；人设四项能力 | 没有读知识能力则上下文只留最小公开身份 |
| 分层检索 | 默认策略：档案 + 经历路由 + 向量 | 对照实验还有「只摘要」「只向量」「档案+向量不走经历」 |
| 经历扩一两跳 | 按时间后继、因果边扩展 | 服务「上次为什么升级/承诺」这类问题，不是社区检测 |
| 向量与关键词融合 | 近邻检索 + 全文检索，倒数排名融合 | 再加重排和去重，避免相近切片占满窗口 |
| 按相关度裁窗 | 上下文编译按预算裁剪 | 先删低分细节，尽量保住高分依据 |
| 丢掉瞎编的依据 | 引用必须是本轮注入集合的子集 | 模型返回的编号不在集合里就丢弃 |
| 待确认队列 | 收件箱 | 抽取和冲突建议可以来自推理模型，落库必须人确认 |
| 生成忠实度 | 针对本轮注入文本的忠实度评分 | 隔离题出现禁读内容直接记泄漏，不拿生成分投票 |
| 换 Spring 怎么做 | 六边形：领域 / 应用 / 端口 / 适配器 | Controller = 入站适配；JPA Entity 不出领域包 |
